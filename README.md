#  ALL_ABOUT_PYTHON

A collection of Python programs covering core programming concepts, Object-Oriented Programming (OOP), exception handling, file handling, data structures, and practice exercises. This repository was created to strengthen Python fundamentals through hands-on coding.

---

## Topics Covered

### Python Basics

- Variables & Data Types
- Operators
- User Input
- Loops
- Conditional Statements (if-else, match-case)
- Functions
- Strings

### Object-Oriented Programming (OOP)

- Classes & Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism

### Advanced Python

- Exception Handling
- File Handling
- Modules & Packages
- Lists
- Tuples
- Sets
- Dictionaries
